# Data

Everything the model reads is in this folder, except the property records
described under [Proprietary data](#proprietary-data), which enter only as
summary counts (`derived/home_value_counts.json`).

- `raw/` files as received from their source, renamed only, except the MVR
  workbook, which the project compiled (see below).
- `derived/` tables prepared from public sources, plus the intermediate tables
  the pipeline writes (`scenarios/`, `takeup/`, `baseline_totals.csv`). Every
  file under `derived/scenarios`, `derived/takeup` and `baseline_totals.csv` is
  regenerated by `make inputs`.

Statutory parameters (36 M.R.S. §5219-KK for the Fairness Credit, the $25,000
homestead exemption and its 76% reimbursement, tax years 2024 to 2026) are
written into `model/ptfc_engine.py` and `model/ptfc_recalibrate.py`. They match
the Maine parameters in [PolicyEngine US](https://github.com/PolicyEngine/policyengine-us);
`model/validate_against_policyengine.py` compares the credit formula with it.

## Proprietary data

**Property records (ATTOM).** The homestead scenarios need to know how many
homes are worth less than a proposed exemption, because a home cannot be
exempted beyond its own value. That distribution comes from ATTOM property
records, which are licensed and are not included. The model uses only an
aggregate: counts of owner-occupied homes by $1,000 value band from $25,000 to
$100,000, plus the count at $100,000 and above (150,414 homes in all), in
`derived/home_value_counts.json`, read by `model/he_resolve_net.py`.
`tools/home_value_counts.py` rebuilds that file from any list of owner-occupied
home values, such as a parcel extract, so the licensed records are not needed
to update it.

**Municipal commitment books.** Five of the six commercial examples in the
Relief Explorer (businesses in Bangor, Camden, Raymond and York, and an apartment
complex in Bangor) use one property's assessed value and annual bill as shown in
its town's tax commitment book (fiscal year 2026 for Bangor and Camden; see
`model/commercial_archetypes.py`). The Gardiner example is not a single property:
it uses a typical assessed value at the town's tax rate. Only these figures are
used; they are written into `model/commercial_archetypes.py`. Commitment books
are public records held by each municipality.
